# 🛒 Shopping-Cart

A simple and responsive **Shopping Cart web application** built using **React + Redux**.  
This project demonstrates essential e-commerce cart functionality such as adding items, updating quantities, removing items, and calculating totals — with clean and maintainable state management.

## 🎯 Features

✔ Add products to cart  
✔ Increase or decrease product quantity  
✔ Remove items from the cart  
✔ Real-time cart summary (items & total amount)  
✔ Responsive UI  
✔ State management using Redux Toolkit
